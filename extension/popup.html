Cara Pakai

  1. Login di jkt48.com.
  2. Buka halaman event/tiket yang diinginkan.
  3. Kode event otomatis terdeteksi dari link URL (contoh EX5B99).
  4. Klik Cek Kuota untuk melihat daftar kuota.
  5. Centang Auto-refresh untuk pantau berkala dengan alarm suara saat kuota restock.
